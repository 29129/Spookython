# Datos de OpenStreetMap

`manta.osm.json` es una extracción de calles alrededor del centro de Manta. Se usa para generar `src/data/manta.graph.json` mediante `npm run map:build`.

Los datos de OpenStreetMap se distribuyen bajo la licencia Open Database License (ODbL). Atribución: © OpenStreetMap contributors — https://www.openstreetmap.org/copyright.

El grafo de la demo conserva 300 intersecciones conectadas del recorte y 424 segmentos. Los cuatro refugios son nodos de la red elegidos para distribuirlos por el área; son ubicaciones de demostración, no refugios oficiales verificados.
